# Qwen2/2.5

## 模型简介

Qwen2 和 Qwen2.5 是阿里通义千问第二代大语言模型，支持 0.5B ~ 72B 多种参数规模。

## DCU 适配注意

- Qwen2 和Qwen2.5 原生支持 bf16，在 DCU 上运行稳定
- MoE 模型的激活参数很小，实际显存需求低于同等 dense 模型
